# João Guilherme — Portfólio (redesign)

Portfólio pessoal em HTML, CSS e JavaScript puros, sem build e sem dependências de framework.

## Direção visual
- Paleta: `#080D18`, `#111C2D`, `#2589F5`, `#58C7FF`, `#F2F5FA`.
- Identidade premium tecnológica com tipografia Inter + JetBrains Mono.
- Gradientes tipográficos, detalhes de terminal, grid sutil e microinterações.
- Conteúdo prioriza recrutadores e oportunidades profissionais, mantendo uma rota clara para contatos de projetos.

## Páginas
- `index.html`: apresentação, sobre, stack, projetos, experiência, formação e contato.
- `experiences.html`: histórico profissional detalhado.
- `educations.html`: formação e links para certificados.
- `404.html`: página de erro personalizada.

## Como executar
Abra `index.html` no navegador ou rode um servidor estático:

```bash
python -m http.server 8000
```

Acesse `http://localhost:8000`.

## Observação sobre os arquivos originais
Para manter o ZIP leve e não duplicar PDFs/imagens de grande tamanho, as imagens do retrato, preview do projeto, favicon, currículo e certificados são carregadas diretamente do repositório original público `jgdomingos/portfolio` por URLs `raw.githubusercontent.com`. Se quiser uma cópia totalmente offline, baixe a pasta `assets` do repositório original e substitua os links externos pelos caminhos locais correspondentes.

## Personalização
- Cores e tokens: `assets/css/variables.css`
- Estilos: `assets/css/main.css`
- Menu, idioma, animações e ano do rodapé: `assets/js/main.js`

## Tecnologias
HTML5 · CSS3 · JavaScript · GitHub Pages
